# 建築物監造流程｜完整自學課程

建築監造觀念的完整自學課程網頁。本專案以台灣現行法規為依據，系統化整理建築物監造的核心觀念、法定表單與法源條文，並標註每個環節的「軟體化切入點」，作為未來開發建築師事務所監造軟體的需求基礎。

整理者：初樸建築師事務所 PROTOPLAIN

## 線上閱讀

網站網址：https://pp0514-hill.github.io/arch-supervision-course/

## 內容架構

課程共 12 個 Lessons，分為 5 個學習階段（法制基礎、計畫與品質保證、現場執行與紀錄、計價與結案、風險與系統整合），另含附錄表單與連結。每課依序拆解為：導讀、學習目標、對應法定表單、法源條文全文、重點圖表、軟體化切入點、自學任務。

## 法源依據

建築法、建築師法、政府採購法，以及行政院公共工程委員會相關規範。法條全文取自現行版本（屬公開法律）。

## 未來規劃：監造軟體

本網頁的最終目的，是依課程中標註的「軟體化切入點」發展成事務所內部使用的監造軟體。每個切入點皆以四個屬性描述：觸發時機、表單欄位、簽核關卡、保存年限，構成軟體的需求骨幹。
